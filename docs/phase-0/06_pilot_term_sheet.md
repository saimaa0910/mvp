# 📋 Pilot Commercial Term Sheet

### K Mati | Kushagramati Analytics Pvt Ltd
### Date: September 2026

## 1. Parties

| Party | Role |
|---|---|

## 2. Scope of Work

### 2.1 Deliverables

| # | Deliverable | Description |
|---|---|---|
| D1 | Platform Prototype | Interactive clickable prototype covering all 7 modules |
| D2 | Platform Development | Fully functional web platform deployed on cloud |
| D3 | Hardware Procurement & Setup | Desktops, tablets, printers, UPS for 20 clinics |
| D4 | Training | In-person role-specific training for all staff at 20 clinics |
| D5 | Go-Live Support | On-site support for first 5 days at each clinic |
| D6 | Helpdesk | Phone + WhatsApp support during clinic hours for pilot duration |
| D7 | Analytics Dashboards | Clinic, zonal, and commissioner dashboards |
| D8 | VAPT | Vulnerability assessment by CERT-In empanelled auditor |
| D9 | Documentation | User manuals, admin guide, API documentation, data dictionary |
| D10 | Pilot Acceptance Report | KPI assessment, learnings, recommendations for citywide |

### 2.2 Functional Modules Included

1. Patient Registration & Queue Management (ABHA-ready)
2. Triage / Nurse Vitals Station
3. Doctor EMR Console (templates, Rx, lab orders, referrals)
4. Pharmacy Dispensing & Stock Management
5. Lab & Diagnostics
6. Referral Tracking
7. Analytics Dashboards (3 tiers)
8. ABDM/ABHA Integration (capture + verification)
9. Offline Support
10. Bilingual Output (Kannada + English)

## 6. Data & Intellectual Property

### 6.1 Data Ownership

| Aspect | Owner |
|---|---|
| All patient data, visit records, clinical data | **Client (GBA / BBMP)** — 100% |
| Platform source code | **K Mati** (licensed to Client for use) |
| Customizations built specifically for this project | **Joint ownership** (Client may use; K Mati may reuse for other government projects) |
| Analytics models and algorithms | **K Mati** (insights and reports belong to Client) |

### 6.2 Data Portability

- Client may request full data export at any time in open formats (CSV, JSON, SQL dump)
- K Mati will provide complete data handover within **30 days** of contract termination
- Open API documentation provided for third-party integration

### 6.3 Confidentiality

- Both parties agree to maintain confidentiality of all project data
- K Mati employees sign individual NDAs before accessing production data
- No patient data may be used for K Mati's own research/commercial purposes
